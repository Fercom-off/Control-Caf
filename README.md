# ☕ Control Cafetería

Sistema de punto de venta (POS) para cafetería con funcionamiento offline y diseño responsive para teléfono, tablet y PC.

## Estructura de archivos
- `index.html` - Interfaz principal con íconos vectoriales SVG limpios.
- `style.css` - Estilos responsivos para teléfono, tablet y escritorio.
- `app.js` - Lógica de ventas, carrito, caja y base de datos IndexedDB.
- `manifest.json` - Configuración para instalar como app (PWA).
- `service-worker.js` - Caché local para funcionamiento sin internet.
- `icons/` - Íconos PNG en alta resolución (192, 512, maskable y Apple).
